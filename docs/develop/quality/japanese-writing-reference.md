# 日本語執筆ガイド参考

## 目的

本書は、[日本語執筆ガイド](./japanese-writing.md)の規則を適用するときに参照する説明、例、表記一覧、参考資料をまとめます。通常の成果物作成では、必須ガイドだけを確認します。

## 構成の例

### 結論を先に示す

避ける例:

> 複数の方式を調査し、それぞれの利点と欠点を比較しました。その結果、ハイブリッド方式が適切だと考えます。

推奨例:

> ハイブリッド方式を採用します。WinEventの即時性とポーリングの再同期を併用できるためです。

読み手が全体像を把握してから詳細を読めるようにします。手順は時系列、比較は同じ観点、規則は重要度または利用順に並べます。

1文には、原則として1つの主要な内容を記載します。文字数による機械的な上限は設けず、主語と述語、修飾語と被修飾語の関係を一度で理解できる長さを基準にします。

### 主体と行動を明確にする

誰が何をするかが重要な場合は、主体を省略しません。責任の所在を曖昧にする受動態や無主語文を避けます。

避ける例:

> エラーとして処理されます。

推奨例:

> Application層は、この結果をタイムアウトとして扱います。

### 修飾関係を近づける

修飾語は、修飾する語の近くに置きます。長い修飾節が続く場合は、文を分けます。

### 否定を重ねない

二重否定や否定の連続を避け、肯定形で表現します。

避ける例:

> 候補が一意でない場合に、処理を続行しないことはありません。

推奨例:

> 候補が一意でない場合、処理を停止します。

### 指示語に依存しない

「これ」「それ」「前述の内容」が何を指すか曖昧な場合は、対象の名称を書きます。

## 事実と判断の例

| 種類 | 意味 | 表現例 |
| --- | --- | --- |
| 事実 | コード、実行結果、一次情報などで確認できる内容 | 「構文解析は成功しました」 |
| 推論 | 確認した事実から導いた解釈 | 「この結果から、待機処理が原因だと推測します」 |
| 判断 | 採否や方針として決定した内容 | 「Option 3を採用します」 |
| 提案 | まだ決定されていない推奨 | 「Option 3を推奨します」 |

事実には確認方法または参照先を示します。推論には根拠を添え、事実として断定しません。提案には、利点、欠点、推奨理由を添えます。

## 文体の詳細

### 本文

説明、手順、利用者向けの文章には、敬体を使用します。要件、規則、Acceptance Criteriaなど、満たすべき条件を列挙する箇所では常体を使用できます。

### 見出し

見出しには、体言止めまたは簡潔な常体を使用します。文末に句点を付けません。同じ階層では、見出しの形式をそろえます。

### 箇条書き

1つの箇条書きでは、敬体、常体、体言止めのいずれかに統一します。完全な文には句点を付け、語句だけの項目には付けません。チェックリストと要件の一覧には、原則として常体を使用します。

## 表記の詳細

### 文字とスペース

- 漢字、ひらがな、カタカナは全角で表記する
- 数字とアルファベットは半角で表記する
- 日本語と半角の数字・アルファベットの間に、原則としてスペースを入れない
- Markdown構文、コード、コマンドでは、構文が要求する半角記号とスペースを使用する
- 日本語の補足には全角かっこを使用し、コードや英語には半角かっこを使用する

### 漢字と送り仮名

常用漢字と現代仮名遣いを基本とし、動詞の送り仮名は省略しません。

| 使用する | 避ける |
| --- | --- |
| 取り消す | 取消す |
| 引き渡す | 引渡す |
| 行う | 行なう |
| 現れる | 現われる |

漢字とひらがなのどちらも一般的な場合は、読みやすいひらがなを優先します。

| 使用する | 避ける |
| --- | --- |
| すべて | 全て |
| たとえば | 例えば |
| わかる | 分かる |
| 〜するとき | 〜する時 |
| 〜するうえで | 〜する上で |

固有名詞、法律名、引用、プロジェクトで定義した用語には、正式な表記を使用します。

### カタカナ語

外来語の語尾は、原則として長音を省略しません。

| 使用する | 避ける |
| --- | --- |
| ユーザー | ユーザ |
| サーバー | サーバ |
| コンピューター | コンピュータ |

製品名や公式用語は原文を優先します。長い複合語が読みにくい場合は、文を言い換えます。

定着した短い技術用語は、区切りを入れずに表記します。

### 数字と単位

数量と順序には半角の算用数字を使用し、数値と日本語の単位の間にはスペースを入れません。

- 3件
- 60秒
- 第2段階
- 100%

コード、コマンド、SI単位などに分野固有の規則がある場合は、その規則を優先します。

## プロジェクト用語

| 概念 | 使用する用語 | 補足 |
| --- | --- | --- |
| 製品を操作する人 | 利用者 | UI、要件、ユースケースで使用する |
| 開発作業を行う人 | 開発者 | 開発ガイドで使用する |
| AIエージェントへ依頼する人 | 依頼者 | AIの権限や確認を説明するときに使用する |
| 操作を中止すること | 取消、取り消す | 名詞と動詞を使い分ける |
| 制限時間への到達 | タイムアウト | 「時間切れ」と混在させない |
| Pull Request | PR | 初出で必要な場合だけ正式名称を示す |
| 作業規模の相対見積もり | ストーリーポイント | 一般的な説明で使用する |
| Jiraの見積もりフィールド | `Story Points` | Jiraのフィールド名を示すときに使用する |

ドメイン用語や技術用語を追加するときは、既存文書を検索し、既存の表記へ合わせます。用語の変更は、影響する文書を同じ変更で更新します。
