# プロダクト要件

## 目的

Browser Launcherは、ブラウザウィンドウの大きさと位置を毎回手作業で調整する負担を減らし、必要な画面配置を再現しやすくするためのデスクトップアプリケーションです。

本ドキュメントは「何を実現するか」のSingle Source of Truth（SSOT）です。技術選定、内部構造、OS APIの利用方法などの「どのように実現するか」は、開発ガイドまたはADRで管理します。

## 対象ユーザー

- Windows 11でGoogle Chromeを日常的に使用する人
- 作業開始時や検証時に、Chromeを決まった大きさと位置へ配置したい人
- コマンドを直接入力せず、画面から安全に起動条件を指定したい人

## 用語

| 用語 | 意味 |
| --- | --- |
| 起動操作 | 入力値を検証し、Chromeの新しいウィンドウを1つ開く一連の操作 |
| ウィンドウサイズ | Chromeウィンドウ全体の幅と高さ |
| ウィンドウ位置 | プライマリディスプレイ左上を原点とするX座標とY座標 |
| 使用可能領域 | タスクバーなど、Windowsが予約する領域を除いたプライマリディスプレイの範囲 |
| 論理ピクセル | Windowsの表示倍率を考慮して、利用者へ一貫して提示する座標と寸法の単位 |

## MVPの対応範囲

| 項目 | 対応範囲 |
| --- | --- |
| OS | Windows 11 |
| ブラウザ | Google Chromeの安定版 |
| Chromeの導入方法 | Windows向けの標準的なユーザー単位またはシステム単位のインストール |
| 1回の起動操作で開く数 | 1ウィンドウ |
| 対象ディスプレイ | プライマリディスプレイ |
| 起動時に開く内容 | Chromeに設定された既定の開始ページ |
| 入力方法 | 幅、高さ、X座標、Y座標を画面から指定 |

対応範囲は、最初に実用可能な最小単位を検証するために限定します。プロダクト名の「Browser」は将来の複数ブラウザ対応を妨げませんが、MVPで任意の実行ファイルを起動できることは意味しません。

## 主要ユースケース

### UC-01 Chromeを指定位置へ起動する

1. 利用者が幅、高さ、X座標、Y座標を入力する
2. 利用者が起動を指示する
3. アプリケーションが入力値とChromeの存在を確認する
4. Chromeがプロファイル選択画面を表示した場合、利用者が使用するプロファイルを選択する
5. プライマリディスプレイの使用可能領域内へ、Chromeの新しいウィンドウが1つ開く
6. 利用者が起動結果を確認できる

### UC-02 入力を修正する

1. 利用者が空欄、数値以外、範囲外の値を入力する
2. アプリケーションがChromeを起動する前に入力を拒否する
3. 問題のある項目と修正方法が、入力箇所の近くに表示される
4. 利用者が値を修正して再実行できる

### UC-03 Chromeを検出できない場合に対処する

1. 利用者が起動を指示する
2. アプリケーションが対応するChromeを検出できない
3. Chromeは起動されない
4. Chromeのインストール状況を確認するよう利用者へ表示される
5. 内部の探索パスやOSコマンドなど、不要な技術情報は表示されない

### UC-04 起動失敗後に再実行する

1. 入力検証とChromeの検出に成功する
2. OSまたはChrome側の理由で起動に失敗する
3. アプリケーションが失敗を成功として扱わない
4. 利用者に失敗した操作と確認可能な次の行動が表示される
5. 利用者が入力を保持したまま再実行できる

## 機能要件

### 入力

- 幅、高さ、X座標、Y座標を個別に入力できる
- 入力値は10進数の整数として扱う
- 幅と高さは1以上とする
- X座標とY座標は0以上とする
- 指定したウィンドウ全体がプライマリディスプレイの使用可能領域内へ収まる値だけを受け付ける
- 未入力、数値以外、小数、負数、使用可能領域を超える値を起動前に拒否する
- 複数の項目に問題がある場合は、利用者がまとめて修正できるよう各項目の問題を示す

### Chromeの検出

- 対応するChromeがインストールされているか、起動前に確認する
- ユーザー単位またはシステム単位で標準的にインストールされたChromeを対象とする
- Chromeを検出できない場合は起動処理へ進まない
- 利用者に任意の実行ファイルやコマンドライン引数を入力させない
- 現在のユーザー、システム全体の順でWindowsの`App Paths`を探索する
- `App Paths`で検出できない場合は、ユーザー単位、システム単位の順で標準インストール先を探索する
- 正規化した実行ファイルのパスが許可した標準インストール先と一致し、ファイルが存在する場合だけ採用する

### 起動

- 1回の起動操作につき、Chromeの新しいウィンドウを1つ要求する
- Chromeがすでに起動している場合も、新しいウィンドウを1つ要求する
- Chromeの起動にはアプリケーションが固定した`--new-window`だけを使用し、利用者由来の追加引数を渡さない
- プロセスIDは起動要求の補助情報として扱い、配置対象のウィンドウをプロセスIDだけで確定しない
- Chromeがプロファイル選択画面を表示した場合は、利用者による選択後に開く通常のブラウザウィンドウを配置対象とする
- プロファイル選択中は起動完了として扱わず、利用者へ待機中であることを表示する
- プロファイル選択の待機中は、利用者が起動操作を取り消せる
- プロファイル選択が60秒以内に完了しない場合は待機を終了し、タイムアウトとして扱う
- アプリケーションはChromeのプロファイル情報を読み取らず、使用するプロファイルを自動選択しない
- Chromeに設定された既定の開始ページを開く
- 入力された論理ピクセルのサイズと位置を、Windowsの表示倍率を考慮して起動処理へ渡す
- 起動要求がOSへ正常に受け付けられた場合だけ、利用者へ成功を表示する
- 同じ入力で起動操作を繰り返すことを許可する。複数ウィンドウを一括して配置する機能とは区別する

### 結果表示

- 入力不正、Chrome未検出、起動失敗、取消、タイムアウトを区別して表示する
- 利用者が修正可能な場合は、原因と次の行動を表示する
- 失敗、取消、タイムアウト後も入力値を保持し、修正または再実行できる
- 内部パス、OSコマンド、スタックトレースを利用者へ表示しない

## エラーと部分的失敗

| 状態 | 期待する振る舞い |
| --- | --- |
| 入力不正 | Chromeを起動せず、対象項目と修正方法を表示する |
| Chrome未検出 | 起動処理へ進まず、インストール状況の確認を促す |
| Chrome起動失敗 | 成功を表示せず、再実行可能な状態を保つ |
| プロファイル選択を取り消す | 成功を表示せず、入力値を保持して再実行可能な状態へ戻る |
| プロファイル選択を60秒以内に完了しない | 成功を表示せず、タイムアウトを表示して入力値を保持したまま再実行可能な状態へ戻る |
| 位置・サイズをOSまたはChromeが調整 | 要求値どおりに配置できなかったことを検出可能にする。具体的な検出方法は設計時に決定する |
| 複数項目の入力不正 | 最初の1件だけでなく、確認できた問題をまとめて表示する |

MVPでは1回の操作で1ウィンドウだけを起動するため、複数ウィンドウの一部だけが起動する部分的失敗は発生しません。複数ウィンドウ対応時に、成功分の扱いと再実行方法を改めて定義します。

## 非機能要件

### セキュリティ

- 任意の実行ファイル、シェルコマンド、追加のコマンドライン引数を利用者に指定させない
- 入力値を文字列連結したシェルコマンドとして実行しない
- Chromeの実行に必要な最小限の権限で動作する
- 入力値、エラー、ログへ秘密情報や不要な個人情報を含めない

### ユーザビリティ

- 入力項目には内容と単位が分かるラベルを表示する
- キーボードだけで入力と起動操作を実行できる
- 色だけで入力エラーや起動結果を伝えない
- 起動処理中、成功、失敗の状態を区別して表示する

### 信頼性

- 入力不正やChrome未検出を、クラッシュや予期しない終了として扱わない
- 失敗後にアプリケーションを再起動せず再試行できる
- 同じ入力に対する検証結果が、実行のたびに変わらない

### プライバシー

- 閲覧履歴、Cookie、Chromeプロファイルの内容を収集しない
- 起動結果や入力値を外部サービスへ送信しない

## 対象外

- Windows 10、Linux、macOSへの対応
- Microsoft Edge、Firefox、ChromiumなどGoogle Chrome以外のブラウザ
- 任意の実行ファイルやブラウザ実行パスの指定
- URL、Chromeプロファイル、追加の起動引数の指定
- Chromeプロファイルの自動選択
- 複数ウィンドウの一括起動と自動配置
- セカンダリディスプレイとマルチディスプレイ
- 入力値の保存、プリセット、履歴
- Chromeのインストール、更新、修復
- アプリケーションの自動更新
- テレメトリーとクラウド同期
